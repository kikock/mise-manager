## 2. 核心专项详细档案 (Key Features)

### 2.1 [v1.5.0] 现代全景主题与 40+ 调色盘系统
* **工程背景**：原版本的主题切换仅提供普通的三个按钮（深色、浅色、跟随系统），缺少多样化的色彩表现力与品牌强调色个性化切换。
* **技术重构方案**：
  1. 新增 `renderer/js/theme.js` 专用主题模块，定义标准主题配置持久化协议（`misemanager_theme_config_v2`）；
  2. 预设 **28 款浅色系典雅色卡**（雪白、冷灰、暖象牙、冰蓝、薄荷、莫兰迪等）与 **8 款精雕细琢深色系色卡**（深邃黑、纯黑、星夜蓝、冷杉绿、极光紫等）；
  3. 增加 **高保真分段控制器**（`theme-segmented`）与 **iOS/Fluent Switch 开关**，支持开启自定义强调色并提供 11 款微软精选强调色（微软蓝、星空蓝、极光青、翡翠绿、炽焰橙、紫罗兰等）快速点选；
  4. 自动覆盖并动态注入 CSS 变量：`--bg-base`、`--sidebar-bg`、`--card-bg`、`--accent`、`--accent-hover`、`--accent-light` 等。
* **受影响文件**：
  - `renderer/js/theme.js` *(全新创建)*
  - `renderer/css/fluent.css` *(追加调色盘色球、分段控制器与 Switch 开关样式)*
  - `renderer/index.html` *(重写外观主题卡片)*
  - `renderer/js/app.js` *(接入全景主题与色球点击交互)*

### 2.2 [v1.7.0] 全软件弹窗美化与原生提示彻底消除
* **工程背景**：在“从 Windows 用户环境变量中清除”、“从 PowerShell Profile 中移除激活脚本”以及“彻底卸载 mise 核心与数据”三个关键操作中，原代码使用了浏览器的同步阻塞原生 `window.confirm()`，视觉白底丑陋且缺乏危险层级警示。
* **技术重构方案**：
  1. 在 `renderer/js/theme.js` 中构建 Promise 化的 `showConfirmModal` 核心组件，支持 `danger`、`warning`、`info` 三种视觉层级；
  2. 采用 Fluent 亚克力磨砂毛玻璃遮罩（`backdrop-filter: blur(12px)`）、优雅弹性微动画（`modalIn`）、自动聚焦与 Enter/Esc 快捷键支持；
  3. 彻底替换 `removeEnvSettings`、`removePwshProfileSettings` 与 `uninstallMise` 中的 3 处原生 `confirm()` 调用，以高颜值模态弹窗与醒目红色危险按钮（`.btn-danger-confirm`）保障数据资产安全。
* **受影响文件**：
  - `renderer/js/theme.js`
  - `renderer/js/app.js`
  - `renderer/css/fluent.css`
