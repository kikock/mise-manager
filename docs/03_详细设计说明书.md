## 1. 核心数据结构与配置模型

### 1.1 应用运行时配置契约 (`AppConfig`)

配置文件由 Rust 内核通过 `serde_json` 持久化存储于 `%APPDATA%\com.kikock.misemanager\config.json`：

```typescript
export interface AppConfig {
  miseRootDir?: string;    // 用户自定义统一主目录 (默认 [AppBaseDir]\mise)
  miseDataDir?: string;    // 数据存储目录 (默认 [miseRootDir]\data)
  miseBinDir?: string;     // 垫片 shims 目录 (默认 [miseDataDir]\shims)
  miseBinPath?: string;    // 手动指定的外部 mise.exe 绝对路径
  proxy?: string;          // 自定义网络代理地址 (如 http://127.0.0.1:7890)
  theme?: 'dark' | 'light' | 'system'; // 用户首选界面主题
}
```

### 1.2 市场缓存与工具元数据模型 (`ToolSummary`)

用于应用生态市场展示与本地缓存：

```typescript
export interface MarketCacheData {
  cachedAt: number;        // 缓存创建时间戳 (毫秒)
  tools: ToolSummary[];    // 官方 1000+ 工具元数据清单
  downloads: Record<string, number>; // 各工具下载热度统计字典
}

export interface ToolSummary {
  name: string;            // 工具标识符 (如 "node", "python", "go")
  description?: string;    // 工具用途详细描述
  homepage?: string;       // 官方主页或开源代码仓库 URL
  category?: string;       // 分类标签 (如 "languages", "cli", "backend")
}
```

### 1.3 已安装工具与版本聚类模型 (`InstalledToolGroup`)

Rust 后端通过扫描向前端返回的已安装工具聚合结构：

```typescript
export interface InstalledToolGroup {
  name: string;                   // 工具名称 (如 "node")
  activeVersion: string | null;   // 当前激活版本 (如 "20.18.0")
  versions: InstalledVersion[];   // 该工具下所有物理安装的版本列表
}

export interface InstalledVersion {
  version: string;                // 版本号标识 (如 "18.20.4")
  installPath: string;            // 本地绝对物理存储路径
  installed: boolean;             // 是否物理完整安装
  active: boolean;                // 是否为当前激活状态
  source: string | null;          // 激活来源 (如 "C:\Users\ck\.config\mise\config.toml")
  requestedVersion: string | null;// 请求版本规格 (如 "20")
}
```

## 2. 核心算法与底层关键实现

### 2.1 基于 Tokio 异步多线程的子进程调度引擎 (`MiseRunner`)

Rust 内核通过 `tokio::process::Command` 启动非阻塞子进程，使用异步 Reader 捕获 stdout 与 stderr：

```rust
pub async fn exec_stream<F>(&self, args: Vec<String>, app: &AppHandle, mut on_chunk: F) -> Result<String, String>
where
    F: FnMut(&str) + Send + 'static,
{
    let mut child = Command::new(&self.exe_path)
        .args(&args)
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .map_err(|e| e.to_string())?;

    let stdout = child.stdout.take().unwrap();
    let mut reader = BufReader::new(stdout).lines();

    while let Ok(Some(line)) = reader.next_line().await {
        on_chunk(&line);
        let _ = app.emit("mise-stream-stdout", &line);
    }

    let status = child.wait().await.map_err(|e| e.to_string())?;
    Ok(status.to_string())
}
```

### 2.2 双轨互补工具扫描与降级算法 (`mise_list_installed`)

当用户安装了大量工具或某些工具损坏时，CLI 命令可能出现超时，系统通过双轨机制实现绝对可靠性：
1. **主轨道 (CLI 快速探测)**：执行 `mise ls --installed --json`（超时设为 2.8 秒）；
2. **辅轨道 (物理目录扫描 `installs/`)**：
   - 遍历 `miseDataDir/installs/` 目录；
   - 枚举子目录获取工具名与物理版本号；
   - 快速合并补充至输出字典；
3. **降级保障**：若主轨道超时或报错，辅轨道扫描算法立即在 3.0 秒内强制收口返回，保证界面绝对不会出现永久旋转加载状态。

### 2.3 基于 Rust `winreg` 的系统环境变量原子写入

在 Windows 下避免命令行脚本转义风险，直接调用 Win32 注册表 API：

```rust
use winreg::enums::*;
use winreg::RegKey;

pub fn add_shims_to_user_path(shims_dir: &str) -> Result<(), String> {
    let hkcu = RegKey::predef(HKEY_CURRENT_USER);
    let (env, _) = hkcu.create_subkey("Environment").map_err(|e| e.to_string())?;

    let current_path: String = env.get_value("Path").unwrap_or_default();
    let mut paths: Vec<&str> = current_path.split(';').filter(|p| !p.is_empty()).collect();

    // 排除旧的或冲突的 shims 路径，确保唯一并置顶
    paths.retain(|p| !p.eq_ignore_ascii_case(shims_dir));
    paths.insert(0, shims_dir);

    let new_path = paths.join(";");
    env.set_value("Path", &new_path).map_err(|e| e.to_string())?;
    Ok(())
}
```

## 4. 容错与恢复策略

| 异常现象 | 诱因剖析 | 处置与恢复预案 |
| --- | --- | --- |
| **GitHub API 限流 (403)** | 短期内频繁触发检查更新 | 内存中对 Releases 实施 10 分钟强缓存；检测失败时优雅降级并展示备用 GitHub 网页链接。 |
| **第三方安装包编译失败** | 缺少对应语言的编译环境 | Rust 子进程实时推送全部错误日志至流式抽屉，安装失败捕获非零退出码，保持界面可用并允许用户复制完整错误堆栈。 |
| **无网络或离线机房部署** | 系统未预装 WebView2 运行时 | 提供 `mise-manager-setup-__VERSION__-full-offline-x64.exe` 完整离线包，内置微软官方 Standalone 安装程序自动静默部署。 |
| **杀毒软件拦截** | 未购买昂贵商业代码签名证书 | 关键安装向导提供清晰 FAQ 引导用户点击“更多信息 -> 仍要运行”，同时支持纯绿色单文件免安装即点即用。 |
