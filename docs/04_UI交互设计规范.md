| 项目 | 内容 |
| --- | --- |
| 产品名称 | Mise Manager — Windows 11 Fluent 风格 mise 版本管理器桌面应用 |
| 设计语言 | Microsoft Fluent Design System (Windows 11 原生规范) |
| 文档版本 | v1.0（正式归档与升级基线） |

## 1. 核心设计理念与视觉基调

Mise Manager 严格遵循 Windows 11 Fluent Design 设计准则，专为桌面开发者打造：
1. **Mica（云母）与 Acrylic（亚克力）质感**：主窗口原生支持 Windows 11 Mica 背景材质，配合细腻的多层亚克力半透明与漫反射投影，营造科技感与高级感；
2. **轻盈与克制 (Subtle & Restrained)**：拒绝花哨刺眼的杂色，以 Win11 官方强调色（Fluent Blue）为主轴，搭配中性灰色调；
3. **状态即时感知 (State Visualized)**：环境变量注入状态、mise 核心就绪状态以高对比度的呼吸圆点指示灯展示；
4. **零跳跃与平滑微动效 (Seamless Transition)**：所有的页面切换、卡片浮动、深浅色模式切换均在 150~250ms 内平滑完成，无白屏闪烁。

## 2. 颜色系统与设计令牌 (Design Tokens)

所有样式通过原生 CSS 变量集中维护于 `renderer/css/fluent.css` 与 `components.css` 中：

### 2.1 核心语义化颜色规范

```css
:root {
  /* Windows 11 经典强调色 */
  --accent-color: #0078d4;
  --accent-light: #2b88d8;
  --accent-dark: #005a9e;
  --accent-subtle: rgba(0, 120, 212, 0.12);
  --accent-glow: rgba(0, 120, 212, 0.35);

  /* 功能状态指示色 */

/* Fluent 深色模式令牌 (默认主题) */
[data-theme='dark'] {
  --bg-app: #16192b;                 /* 深度深蓝暗色底 */

  --text-secondary: #a0a6c2;
  --text-muted: #676e95;
}

/* Fluent 浅色模式令牌 */
[data-theme='light'] {
  --bg-app: #f3f4f8;                 /* 柔和浅灰底 */
```

## 3. 字体系统与排版标准

1. **界面字体栈**：`"Segoe UI Variable Display"`, `"Segoe UI Variable Text"`, `"Segoe UI"`, `"PingFang SC"`, `"Microsoft YaHei"`, sans-serif；
2. **终端与代码字体栈**：`"Cascadia Code"`, `"Consolas"`, `"Courier New"`, monospace；
3. **字阶规范**：
   - **Page Title (页面主标题)**：26px / Semi-Bold / 跟踪间距 `-0.02em`
   - **Section Title (模块大标题)**：18px / Semi-Bold
   - **Card Title (卡片工具名)**：15px / Medium
   - **Body Text (正文描述)**：13px / Regular
   - **Caption / Badge (辅助标签/版本号)**：11px / Medium

### 4.2 核心模块交互规范

#### 1. 首页工作台 (Home Dashboard)
- **就绪指标卡片**：直观展示 mise 核心版本与数据存放路径；
- **状态指示灯**：绿色光晕代表正常运转，灰色代表未初始化；
- **快速入口**：提供一键打开终端、一键补齐所有工具等快捷动作。

#### 2. 应用生态市场 (Market View)
- **搜索与分类**：顶部居中提供宽幅搜索框，带即时清除按钮；下方横向排布分类芯片；
- **瀑布流卡片**：展示工具名称、官方描述、历史下载热度量级徽章；
- **版本弹窗**：点击卡片即时获取可用版本下拉列表，选定后点击“安装”，平滑滑出流式控制台。

#### 3. 已安装工具管理 (Installed View)
- **工具聚合卡片**：一个工具卡片内收纳该语言/工具下的全部物理版本（如 Node.js 包含 18.20.4、20.18.0）；
- **版本激活切换**：提供 `Global` 与 `Local` 单选徽章，点击即触发热切换，无闪烁；
- **物理定位**：每项版本右侧附带文件夹图标，点击一键唤起 Windows Explorer 定位。

#### 4. 路径与环境变量设置 (Settings View)
- **路径重定向**：支持点击“选择目录”弹出 Windows 原生文件夹选择器，自动同步更新配置；
- **环境变量托管卡片**：直观展现 Windows 用户 PATH 与 Profile 激活状态，提供“一键应用”与“一键清除”高对比度按钮。

## 5. 微交互动效与反馈设计

| 交互场景 | 触发时机 | 动效形式 | 持续时长 |
| --- | --- | --- | --- |
| **导航切换** | 点击左侧 Tab | 激活指示条垂直滑动，主工作区内容 `opacity 0 → 1` 伴随 `3px` 位移 | 200ms |
| **卡片悬浮** | 鼠标滑入卡片 | `transform: translateY(-2px)`，边框微亮，阴影加深 | 150ms |
| **流式日志输出** | 安装过程数据流 | 终端输出区自动锁定并平滑滚动至最底部，控制台光标闪烁 | 持续 |
| **一键应用成功** | 环境变量同步完成 | 按钮短暂呈现绿色勾号，状态圆点由红变绿伴随微光晕脉冲 | 300ms |

## 6. 无障碍支持与响应式断点

- **最小窗口尺寸保护**：窗口设定最小限制 `minWidth: 920px`, `minHeight: 620px`，杜绝小屏幕下布局拥挤重叠；
- **自适应栅格**：市场卡片网格根据窗口宽度自适应（`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`）；
- **高对比度文本**：文字与卡片底色对比度严格达到 WCAG AA 级标准（≥ 4.5:1）。
